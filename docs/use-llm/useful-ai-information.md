# understand repo code
 
## High-Level Architecture Skills

### use structured prompting frameworks to force the AI to build a structural mental model
- Directory Progression & Disclosure
  - "Generate a tree-map of the repository layout but omit individual utility files. Group directories by system domain (e.g., Core, Infrastructure, API, Shared)."
- Domain Modeling & Glossary Building
  - "Analyze the core data structures and types. Build a GLOSSARY.md identifying the ubiquitous language of this codebase."

## Detailed Workflow & Runtime Analysis Skills

### Once you have the structural map, switch the AI's mental state from Static (structure) to Dynamic (how data moves).
- The "Trace a Feature" Skill
  - "Act as a runtime debugger. Trace the end-to-end execution path of [Feature X]. List every file, function, and middleware triggered in order from request to response."
- The Reverse-Engineering Spec Skill
  - "Analyze the /src/controllersand/src/services directories. Reverse-engineer them into a clean technical specification sheet detailing the inputs, state mutations, and outputs.
- State-Machine Extraction
  - "Identify where state is preserved in this repository. Draft a Mermaid.js state-transition diagram showing how an object changes state throughout its lifecycle."
